# E：M3评价与结果分析

截至2026-10-11，已完成smoke 20题、dev 50题的六组预测评分，共240条记录、70个不同问题。各组生成覆盖率和评分覆盖率均为100%，最终技术失败为0。eval 200题尚未生成，未纳入本次评价；正式参数尚未冻结。

## 1. 实现范围与接口

E模块接收B整理的问题、参考答案与metadata，以及D生成的预测，按`interaction_id`关联；输出逐条成绩、汇总指标和评价运行记录。检索和生成不接收参考答案。公共输出沿用`m3.v1`接口，入口包括评分、分组比较、请求日志审计和批次合并。

实现位于`src/evaluation/`，命令入口为`scripts/evaluate.py`、`scripts/review_evaluation.py`和`scripts/evaluation_records.py`。比较使用原manifest、预测和运行记录核对数据来源，避免把不同批次或未完成成绩混入同一结论。

## 2. 评价方法

B0仅输入原始问题，B1增加官方Web文本证据。dev的k1、k3、k5使用同一50题及相同生成配置。

预测先经过已核验的`meta-llama/Llama-3.2-1B-Instruct`分词器执行官方75-token截断，再依次进行拒答识别、精确匹配和语义评价。语义裁判只接收问题、参考答案和截断后的回答，不接收组别及检索证据。采用官方提示，裁判模型为AutoDL提供的`DeepSeek-V4.1-Flash`，temperature为0，输出上限4096，超时120秒，SDK与应用自动重试均为0。裁判模型与官方不同，不能将本实验成绩直接视为排行榜同口径成绩。早期1024输出上限的结果单独保留，未混入本次比较。

正确、错误和拒答分别记为C、W、M，成功评分数为N=C+W+M。正确率为C/N，错误率为W/N，拒答率为M/N，truthfulness为(C−W)/N。生成故障标记为`unscored`，裁判故障标记为`error`，分数均保留为null；不将技术故障计为答错或拒答。N为0时比例为null。

smoke B1较B0的正确率增加15个百分点，truthfulness下降0.30；dev B1 k5较B0的正确率增加18个百分点，truthfulness下降0.28。检索增加了作答和答对数量，同时带来了更多错误。B0接近全部拒答，truthfulness接近0不能说明其实用回答能力更强。

在dev的共同50题上，k3较k1多答对1题、答错3题，正确率增加2个百分点，truthfulness下降0.04；k5较k1正确率下降2个百分点，truthfulness下降0.16。因此，若优先考虑truthfulness，当前结果支持将k1作为候选；若优先考虑正确率，可考虑k3，但需同时报告错误率。开发集只有50题，这些结果尚不能证明统计显著或泛化最优，也不能据此声称已完成正式参数选择。

## 4. 复核与错误分析

以seed 42按预测记录分层抽取20条语义评价和10条规则拒答，打乱并隐藏组别，共覆盖28个不同问题。AI辅助复核与原裁判29/30一致，其中语义评价19/20、规则拒答10/10。尚未进行独立人工核查；复核时已接触过早期建议和smoke汇总，因此该一致率仅作辅助参考，不能当作独立人工可靠性验证。抽样与复核原始记录见[复核资料](evaluation_paid_4096_v1/README.md)。

唯一语义分歧为R001：辅助复核认为paper不能直接替换cardboard，建议判为WRONG；原裁判接受相同的生物降解比较方向，判为CORRECT。保留两种意见和原始成绩，未因分歧修改提示或重新评分。

[10个错误分析案例](evaluation_paid_4096_v1/complete_v1/cases.md)保留实际标签、裁判原文和请求证据。例如，目标为empanada mama的门店问题引用了7-Eleven数据，恐龙证据转向另一物种，部分样例涉及植物俗名歧义或Kindle价格方向错误。原因解释由AI辅助分析，仍需人工复查。尚未开展多模态对照实验，暂不能判断图像输入的改善幅度。

## 5. 验证与复现

评价模块通过47项模拟与接口测试，覆盖输入校验、失败恢复、缓存复用、分组统计及比较入口校验。比较时必须提供同目录评价运行记录，核验输入输出SHA256、配置、运行身份、范围和计数，并检查确定性拒答与精确匹配标签；改写成绩的副本会被拒绝。[比较入口验证记录](evaluation_paid_4096_v1/validation/comparison_v1.json)保存了六组240条比较与异常副本检查结果。

六组最终成绩均通过公共验收；240行截断文本、规则标签和已保存裁判响应重算一致。完整评分阶段的42项E测试和更早的公共回归属于历史验证记录，与修复后的47项测试分别保留。离线比较只重算已有成绩的统计，不重新判断语义，也不重新运行检索、生成或付费裁判。

136条拒答由规则确定，104条需语义评价的记录去重为90份不同输入。一次请求耗尽4096输出预算后正文为空，评分停止；手动重试该输入一次后完成其余请求。累计91次真实请求、90次成功、1次失败，提供商返回的`total_tokens`合计236135，包含失败尝试。货币价格未核实，暂不估算费用。早期1024配置的14次请求、36291 tokens另存，未混入上述统计。

环境配置、离线比较、公共验收及新输入预检见[运行说明](evaluation_paid_4096_v1/run.md)。
