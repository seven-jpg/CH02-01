## 方法与范围

B0只用原问题，B1增加Web检索证据；dev的k1/k3/k5来自同一固定50题及相同生成配置。使用已核验Llama-3.2-1B分词器的官方75-token截断、官方提示和三标签规则，AutoDL DeepSeek-V4.1-Flash裁判，temperature=0，max_tokens=4096，超时120秒，SDK和应用重试均为0。语义裁判只收到问题、参考和截断回答，不含组别或检索证据。

CORRECT=+1、WRONG=-1、MISSING=0；accuracy=C/N，错误率=W/N，拒答率=M/N，truthfulness=(C-W)/N，N为成功评分数。技术失败保留null而不计答错。沿用官方提示、分词器与主要计分逻辑，裁判改为第三方提供的DeepSeek模型，并修正故障处理和解析可靠性；不能声称与排行榜完全同口径。
